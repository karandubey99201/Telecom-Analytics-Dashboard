# Telecom Analytics Dashboard

# Project Overview
A professional Telecom Analytics Dashboard built using 
PostgreSQL and Power BI on 10,000+ records.

## Tools Used
- **Database:** PostgreSQL + PgAdmin
- **Visualization:** Power BI Desktop
- **Dataset:** 10,000 rows, 46 columns

## Key Metrics
- Total Revenue: $442.53K
- Total Customers: 10,000
- Average ARPU: $44.29
- Churn Rate: 3.83%

## Dashboard Features
- Revenue by Country
- Churn Analysis by Service
- Network Type Distribution
- Interactive Slicers (Country, Network, Plan)
- KPI Cards

## SQL Queries
- Revenue by Country
- Churn Rate Analysis
- ARPU by Network Type
- Monthly Revenue Trend
